# COMPAS

COMPAS is an open-source, Python-based framework for computational research and collaboration in architecture, engineering, fabrication, and construction.

This documentation covers the host-independent core framework. Integrations with CAD applications and specialized computational backends are maintained as separate projects in the wider COMPAS ecosystem.

## Start here

- [Install COMPAS](getting-started/installation.md) and run the [first examples](getting-started/first-steps.md).
- Explore practical guides under the **Examples** tab.
- Look up packages, classes, and functions under **Reference**.
- Read about development, plugins, and framework concepts under **Background**.

!!! note

    For the wider COMPAS ecosystem, visit [compas.dev](https://compas.dev/).
