# Datastructures

COMPAS provides graph, mesh, volumetric mesh, cell-network, and tree data
structures. They combine explicit topology with geometry and user-defined
attributes while participating in the shared data serialization system.

Begin with [graphs](basics.datastructures.graphs.md) or
[meshes](basics.datastructures.meshes.md). The complete public API is documented
in the [`compas.datastructures` reference](../reference/compas.datastructures.md).
