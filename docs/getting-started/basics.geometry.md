# Geometry

The `compas.geometry` package provides primitives, curves, surfaces, shapes,
transformations, polygonal geometry, intersections, and geometry-processing
algorithms.

Start with [points and vectors](basics.geometry.points_and_vectors.md), then
continue with [planes and frames](basics.geometry.planes_and_frames.md) and
[transformations](basics.geometry.transformations.md). The complete public API
is documented in the [`compas.geometry` reference](../reference/compas.geometry.md).
