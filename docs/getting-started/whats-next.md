# What's Next

If you have successfully installed COMPAS and completed the [first steps](first-steps.md),
you are ready for the next challenge. Where to go from here depends on what you want to do.

- Work through the geometry and data-structure guides in this section.
- Try the runnable examples under the **Examples** tab.
- Use the **Reference** tab when you need the complete public API.
- Read the **Background** tab before contributing to the framework.

If you have questions, visit the [COMPAS forum](https://forum.compas-framework.org).
