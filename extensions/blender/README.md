# COMPAS Blender extension

Source of the [Blender extension](https://docs.blender.org/manual/en/latest/advanced/extensions/getting_started.html) that distributes COMPAS for Blender 4.2 and newer.

* `addon/` contains the extension source: the add-on `__init__.py` and the source `blender_manifest.toml`.
* `build.py` builds the extension packages into `dist/blender`, one per Blender version range and platform,
  bundling the `compas` wheel and all its dependencies (except `numpy`, which ships with Blender).

```bash
invoke build-blender-extension --blender /path/to/blender
```

The manifest `version` is kept in sync by `bump-my-version`; `blender_version_max`, `platforms` and `wheels`
are generated by `build.py` for each build.
